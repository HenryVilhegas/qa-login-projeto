# Projeto QA – Sistema de Login Web

Projeto prático desenvolvido para estudo de Quality Assurance (QA), com foco em testes manuais de um sistema de login web.

## Objetivo
Validar o funcionamento de um sistema de login simulado, identificando falhas funcionais, de validação e de segurança.

## Escopo de Testes
- Validação de campos obrigatórios (CPF e senha)
- Testes de login com dados válidos e inválidos
- Verificação de mensagens de erro
- Cenários negativos de autenticação
- Análise de riscos de segurança (ex: login sem senha)

## Casos de Teste
Os casos de teste estão documentados no diretório  
`casos-de-teste/login-testes.md`

## Tecnologias Utilizadas
- HTML
- CSS
- JavaScript
- Testes Manuais
- GitHub

## Observações
Este projeto não representa um sistema bancário real e foi criado exclusivamente para fins educacionais e prática em QA.
